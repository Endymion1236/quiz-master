# 🎵 Sons personnalisés — Quiz Master

Place tes fichiers MP3 ici pour personnaliser l'ambiance sonore !

## Sons du jeu (pendant les questions)

| Fichier          | Quand il joue                          | Durée conseillée |
|------------------|----------------------------------------|------------------|
| `correct.mp3`   | Bonne réponse                          | 0.5 - 2 sec      |
| `wrong.mp3`     | Mauvaise réponse                       | 0.5 - 2 sec      |
| `countdown.mp3` | Bip du 3-2-1 avant chaque question     | 0.3 - 0.5 sec    |
| `tick.mp3`      | Clic sur un bouton                     | 0.1 - 0.3 sec    |
| `join.mp3`      | Un joueur rejoint la salle             | 0.3 - 1 sec      |
| `launch.mp3`    | Le quiz démarre                        | 1 - 3 sec        |
| `buzzer.mp3`    | Un joueur appuie sur le buzzer         | 0.3 - 1 sec      |
| `steal.mp3`     | Vol de points                          | 1 - 2 sec        |
| `timesup.mp3`   | Temps écoulé                           | 0.5 - 1 sec      |
| `streak.mp3`    | Série de bonnes réponses               | 0.5 - 1 sec      |

## Règles

- **Format** : MP3 uniquement
- **Taille** : < 500 Ko par fichier (sauf lobby.mp3 qui peut être plus gros)
- **Pas obligatoire** : si un fichier manque, le son synthétique prend le relais
- **Noms exacts** : respecte les noms ci-dessus (en minuscules)
